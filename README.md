# Send to Phone

A Lightroom Classic plugin that sends the photo you're working on straight to
your iPhone — instantly, with one keystroke.

Stop exporting to folders, AirDropping, or waiting on iCloud sync. Select a
photo in Lightroom, press **⌥S**, and an Instagram-ready JPEG lands in Messages
on your phone seconds later. Tap once to save it to your camera roll and post.

```
Lightroom Classic ──⌥S──▶ 2048px sRGB JPEG ──iMessage──▶ your iPhone
```

## Install (one line)

```bash
curl -fsSL https://raw.githubusercontent.com/YashaVasilyev/send-to-phone-lightroom/main/setup.sh | bash
```

The script:

1. Downloads the plugin
2. Asks for your phone number (and an optional save path)
3. Installs the [`imsg`](https://imsg.sh) CLI via Homebrew
4. Installs the plugin into Lightroom's Modules folder
5. Binds the **⌥S** shortcut

After it finishes:

1. Quit and relaunch Lightroom Classic
2. Grant **Full Disk Access** to Lightroom Classic (System Settings > Privacy &
   Security > Full Disk Access) — one-time, needed for imsg to stage
   attachments in `~/Library/Messages`
3. Approve the Automation prompt on first use (Lightroom Classic > Messages)
4. Select a photo, press **⌥S**

Prefer to read scripts before running them? Fair:

```bash
git clone https://github.com/YashaVasilyev/send-to-phone-lightroom
less send-to-phone-lightroom/setup.sh
./send-to-phone-lightroom/setup.sh
```

## Requirements

- macOS with Messages signed in to the same Apple ID as your iPhone
- Lightroom Classic (tested on 26.6.2)
- [Homebrew](https://brew.sh) (used to install imsg)

## Usage

Select a photo in any module (Library, Develop, etc.) and press **⌥S** — or use
**File > Plug-in Extras > Send to Phone**. A bezel confirms "Sent to phone",
and the JPEG appears in Messages on your phone within seconds.

The export is tuned for Instagram: 2048px max edge, sRGB, JPEG at 90% quality,
metadata minimized.

## Configuration

Everything is configurable in **File > Plug-in Manager > Send to Phone**:

- Phone number
- Export folder (temp save path)
- Max edge in pixels (default 2048)
- JPEG quality (default 0.9)
- Keyboard shortcut (Option+S, Command+P, or Control+Option+Command+S) —
  click **Apply**, then relaunch Lightroom

Settings can also live in `Config.lua` (generated by `setup.sh`, gitignored);
the Plug-in Manager values take priority. Edit it any time and reload the
plugin in Plug-in Manager:

```lua
return {
    phone_number = "+15551234567",
    temp_dir = "/tmp/send-to-phone",
}
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| "Not delivered" / nothing arrives | Check Messages on the Mac is signed in and can send to your number |
| Permission error saving to `~/Library/Messages/...` | Grant Full Disk Access to Lightroom Classic |
| Shortcut doesn't fire | Quit and relaunch Lightroom (shortcuts load at launch) |
| "No phone number configured" | Run `setup.sh` again, or create `Config.lua` from `Config.lua.example` |

## Why iMessage?

The alternatives don't work for one-click, zero-phone-setup delivery:
AirDrop has no scriptable API; push services (Pushover, ntfy, Telegram) all
require a phone app; iCloud Photos sync works but can take minutes. iMessage
is instant and needs nothing installed on the phone.
